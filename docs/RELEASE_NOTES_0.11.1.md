# Mystery 0.11.1 · 星云之间

一个因为个人命理与占卜爱好而做的集成小玩具：本地排盘、和朋友抽牌、记录生日，也能在专注时播放音乐。

- 四柱八字、西方占星、紫微斗数、印度占星与可视化命盘。
- 塔罗、雷诺曼、六爻、梅花易数和答案之书的三维交互。
- 离线生日簿地球、城市搜索、人物备注和跨时区生日提醒。
- 本地音乐、音频直链及星云／地球专注场景。
- 可选 AI 解读和追问；本地功能无需注册。
- 透明银灰磨砂导航与工具栏，让操作界面保持视觉重点。

## 下载与安装

Windows x64：下载 `Mystery-0.11.1-setup.exe`；需要 Windows 10/11、WebView2 和 WebGL 2。此为最新源码重建版，已含新版磨砂界面。当前 Windows 安装包未进行代码签名。

macOS：已本地构建 Apple Silicon arm64 PKG，构建系统 macOS 27.0.1。14 组冻结自检通过。应用 ad-hoc 签名，PKG 未签名、未公证；原生 UI、权限及干净机器安装尚待验收。Intel 和最低系统版本未验证。当前不发布安装包，仓库保持 private。

附件中的 `SHA256SUMS.txt` 用于核对下载文件。Windows 对应源码为 `Mystery-0.11.1-source.zip`；Mac 对应源码另按架构命名。固定版本 `pyswisseph-2.10.3.2.tar.gz` 和许可附件一并提供。
